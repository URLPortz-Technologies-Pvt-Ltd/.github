## What is URLPortz?

If you work with Kubernetes, you've lived this:

- `kubectl port-forward` dies every few minutes — you retype it
- You have 5 terminals open for 5 services
- You can never remember which port maps to which service
- Your dev/staging/prod URLs are scattered across browser bookmarks, Notion, Slack

**URLPortz fixes all of this in one place.**

---

## Key Features

| Feature | What it does |
|---|---|
| ⚡ **Auto-reconnect Port Forwards** | Detects dropped `kubectl port-forward` and reconnects in 5 seconds — automatically |
| 🔗 **URL Library** | Organise dev, staging, prod URLs per environment. One click to open |
| 📓 **Developer Notebooks** | Local markdown notes linked to your running services. No cloud, no sync |
| 🖥️ **Runs locally** | Nothing sent to servers. Your kubeconfig, your data, your machine |
